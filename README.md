# 교직원수련원 선착순 예약 도우미

전북특별자치도교육청교직원수련원(office.jbedu.kr/jbetc) 선착순 객실 예약을 돕는
Tampermonkey 유저스크립트입니다.

## 설치
1. 크롬에 Tampermonkey 확장 설치 후, 확장 설정에서 개발자 모드
   (또는 '사용자 스크립트 허용')를 켭니다.
2. 아래 링크를 클릭하면 Tampermonkey 설치 화면이 뜹니다. [설치]를 누르세요.
   https://raw.githubusercontent.com/ggulbang1004/jbetc-reservation/main/jbetc_reservation.user.js
3. 수련원 사이트에 로그인한 뒤 예약하기 페이지에 들어가면
   오른쪽 위에 조작 패널이 나타납니다.

## 사용법
- 날짜·숙박일수·숙박인원을 맞추고 [시작(새 세션)]을 누르면, 빈 객실이 있을 때
  우선순위에 따라 자동으로 예약을 시도합니다.
- 연습 모드(기본 켜짐)에서는 마지막 예약하기 직전에 멈춥니다.
  실제 예약할 때만 연습 모드를 끄세요.
- 건물 선택(본관만/별관만/교대), 예약 방식(우선순위/아무 방이나)을 고를 수 있습니다.

## 업데이트
스크립트에 @updateURL이 지정되어 있어, 이 저장소에 새 버전이 올라오면
Tampermonkey가 자동으로 업데이트합니다.
